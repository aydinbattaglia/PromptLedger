PromptLedger

How PromptLedger works

A reference guide to every feature, field, and status indicator.

Getting started
1
Visit your billing page on each tool PromptLedger's plan detector runs automatically on Runway, Midjourney, and ElevenLabs billing pages and saves your credit rate. You can also set a rate manually from the popup.
2
Generate as normal The extension intercepts network traffic in the background. Every time a generation completes, it records the credit delta, converts it to a dollar cost using your plan rate, and stores it locally.
3
Review your usage in the dashboard Open the popup and click "Open full dashboard" to see your spend over time, filter by tool or project, export to CSV, or delete individual records.
How costs are calculated

Plan rate

Each tool prices credits differently. PromptLedger stores a plan rate — the number of credits (or characters, or GPU-hours) you get per dollar — and uses it to convert credit deltas into a dollar cost:

cost = credits_used ÷ plan_rate

Rates are detected automatically from your billing page or set manually in the popup. You can override a detected rate at any time.

Credit delta

When a generation starts, the extension reads your current balance. When it completes, it reads your balance again. The difference is credits_used. This works across all three tools even though they use different balance formats (Runway: credits, Midjourney: GPU hours, ElevenLabs: characters).

Log table fields
Field What it means
Time When the generation started, in your local timezone.
Tool Which service was used: runway, midjourney, or elevenlabs.
Model The specific model or plan tier detected from the request, e.g. gen3a_turbo. May show unknown if the model couldn't be parsed from the request.
Prompt The text prompt sent with the generation, if it was present in the intercepted request. Shows — if not captured.
Project A project tag you assign to group related generations. Can be set before generating (via the popup) or retroactively using the dropdown in this column.
Credits The number of credits, characters, or GPU-hours consumed. Shows — if the record is flagged.
Cost Dollar cost, calculated as credits ÷ plan_rate. Shows — if flagged or if no plan rate is set.
Flagged records
flagged

A record is flagged when the extension cannot trust the cost reading. Flagged records have credits_used: null and cost_usd: null — they appear in the log but are excluded from totals and charts.

Reason 1 — Generation timed out

If no completion signal arrives within the timeout window (5 minutes for Runway, 3 minutes for Midjourney, 1 minute for ElevenLabs), the record is saved as flagged. The generation may have completed but the balance change couldn't be captured in time.

Reason 2 — Delta failed validation

When a completion does arrive, two checks run:

Hard cap: The delta exceeds an absolute ceiling per tool (2,500 credits for Runway, 60 GPU-hours for Midjourney, 100,000 characters for ElevenLabs). Anything above these values is almost certainly a bad reading from a page refresh or balance resync.

5× EMA rule: The delta is more than 5× your exponential moving average for that tool (weighted toward recent generations, α = 0.3). This catches anomalous spikes relative to your normal usage patterns.

If either check fails, the delta is discarded and the record is flagged. The EMA updates only from valid (unflagged) generations, so a false positive won't skew future estimates.

Tip: A high flagged count usually means your plan rate isn't set or is stale. Visit your billing page to let the detector refresh it, or set the rate manually in the popup.

Project tags
my-campaign

Project tags let you group generations by campaign, client, or workflow and see their cost breakdown separately.

Setting a tag before you generate

Open the popup and select a project from the "Active project" dropdown (or create one with the + button). All subsequent generations are tagged with that project until you change it or set it back to "None".

Tagging existing records

In the dashboard log table, each row has a Project dropdown. Select a project (or "None") to update that record immediately — no save button needed.

Filtering by project

Use the "Project" filter dropdown in the dashboard filter bar to show only records belonging to a specific project. The dropdown auto-applies when changed.

Dashboard features

Summary cards

Total cost, total credits, generation count, and flagged count — all scoped to your current filters.

Daily spend chart

A line chart of dollar spend per day. Toggle between 30-day and 90-day views using the buttons in the chart header. The range always ends today and counts back from there.

By-tool doughnut

Shows spend proportion across tools for the current filter selection. Displays a grey placeholder when there is no cost data.

Filters

Tool and Project filters apply immediately on change. Date range and prompt search require clicking Apply (to avoid filtering on partial input). The Clear button resets all filters at once.

CSV export

Exports all currently filtered records (not just the current page) as a CSV file. The filename includes today's date: promptledger-export-YYYY-MM-DD.csv. All schema fields are included.

Delete and Clear all

The ✕ button on each row deletes that record permanently from IndexedDB. "Clear all" in the header deletes every record after a confirmation prompt. Both actions are irreversible — export first if you need to keep the data.

Privacy: All data is stored locally in your browser's IndexedDB. Nothing is sent to any server. The extension only has access to the three domains listed in its permissions.

Currency conversion

By default all costs are displayed in US dollars (USD). You can switch to any of the ten supported currencies using the dropdown in the dashboard header:

USD · EUR · GBP · JPY · CAD · AUD · CHF · CNY · INR · MXN

How rates are fetched

Exchange rates are pulled from frankfurter.app (European Central Bank data) automatically in the background — once when you first install the extension and then every 24 hours via a scheduled alarm. No API key is required and no data about your usage is sent to the rate service.

If the fetch fails (e.g. you're offline), the most recently cached rates remain in use. The date rates were last updated is stored in chrome.storage.local as exchange_rates_updated.

What gets converted

Switching currency converts every cost display on the page immediately:

  • Summary cards (Total cost)
  • Daily spend chart — axes, tick labels, and hover tooltips
  • By-tool doughnut chart — tooltip amounts
  • Log table — Cost column
  • Popup — monthly cost and per-tool cost breakdown

Stored data stays in USD

All records in IndexedDB are always saved with cost_usd in US dollars. Currency conversion is display-only — switching currencies never modifies your stored data. CSV exports also use USD so they remain consistent regardless of your display setting.

Preference is saved: your selected currency persists across sessions. The popup reads the same setting and converts its cost displays to match.

Pausing tracking

The "Pause" button in the popup header stops all capture. Generations made while paused are not logged. Click "Resume" to start recording again. The paused state persists across browser restarts.
