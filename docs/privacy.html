PromptLedger Privacy Policy

Last updated: July 2026

PromptLedger is a browser extension that tracks credit usage on AI creative tools. All data is stored locally on your device. Nothing is sent to any server operated by PromptLedger.

Data stored locally

PromptLedger stores the following in your browser's IndexedDB and extension storage:

  • Prompt text submitted to supported tools (Runway and ElevenLabs; Midjourney support is experimental)
  • Credits used and estimated cost per generation
  • Timestamp, model name, and optional project tag per generation
  • User-configured settings (budget limits, display currency, detected plan rates)

This data never leaves your device and is never transmitted to PromptLedger or any third party.

Network requests

The only outbound request made by PromptLedger is a daily fetch to api.frankfurter.app to retrieve currency exchange rates. No user data is included in this request.

Data you control

You can clear all stored generation records at any time from the dashboard. Uninstalling the extension removes all stored data.

Permissions

  • storage — saves generation records and settings locally
  • notifications — sends budget alerts when spend limits are reached
  • alarms — schedules the daily exchange rate refresh
  • Host permissions (runwayml.com, midjourney.com, elevenlabs.io) — inject content scripts that observe credit balance changes on these sites only
  • Host permission (api.frankfurter.app) — used solely for the daily exchange-rate fetch described above
